免费获取 API Key（智谱 GLM）

智谱 AI 提供免费 API 额度，注册即可使用。按以下步骤操作，3 分钟配置完成。

  1. 注册 / 登录智谱 AI

    访问 https://bigmodel.cn， 使用手机号注册或登录。

    登录 / 注册页面
  2. 创建 API Key

    登录后进入 API Keys 管理页， 点击「新建 API Key」，名称随意填写，然后复制生成的 Key。

    创建并复制 API Key
  3. 配置插件

    回到插件设置页面，进行以下配置：

    • 预设服务商：选择「智谱 GLM」
    • API Key：粘贴刚才复制的 Key
    • 模型：默认填入免费模型（如 glm-4-flash），可直接使用
    选择 智谱 GLM 并填入 API Key
  4. 测试连接并保存

    点击「测试连接」，看到 OK 提示后点击「保存」即可开始使用。

选模型建议

免费模型可在以下页面查看最新列表和用量限制：

  • 定价页面（bigmodel.cn/pricing）
  • 免费模型文档

免费模型推荐：glm-4-flash（免费）、glm-4.6v-flash（免费，支持视觉）。 如果模型不可用，切换另一个免费模型即可。
